# Fuentes de datos

## 1. DIVIPOLA (DANE - Municipios)

- Dataset oficial de la DIVIPOLA en Datos Abiertos Colombia con el identificador: `gdxc-w37w`.
- Página principal del dataset: https://www.datos.gov.co/Mapas-Nacionales/DIVIPOLA-C-digos-municipios/gdxc-w37w
- Descarga directa CSV: https://www.datos.gov.co/api/views/gdxc-w37w/rows.csv?accessType=DOWNLOAD
- El enlace anterior descarga directamente el archivo CSV completo.

## 2. Open-Meteo (Clima por hora)

- Para evitar errores con caracteres especiales o codificación del navegador, se puede usar la interfaz de configuración visual de Open-Meteo para seleccionar variables e historial, o copiar el endpoint directo de su API histórica.
- Configurador web: https://open-meteo.com/en/docs/historical-weather-api
- Coordenadas de Medellín: Latitude: 6.2518, Longitude: -75.5636
- Rango de fechas sugerido: 2024-01-01 a 2024-01-31
- Variables horarias recomendadas:
  - Temperature (2 m)
  - Rain / Precipitation
- La respuesta puede consultarse en JSON o descargarse desde la interfaz.
- Descarga directa (JSON en navegador):
  https://archive-api.open-meteo.com/v1/archive?latitude=6.2518&longitude=-75.5636&start_date=2024-01-01&end_date=2024-01-31&hourly=temperature_2m,precipitation&timezone=America%2FBogota

## 3. EPM Datos Abiertos / Interrupciones

- EPM reestructuró su portal corporativo, por lo que la página puede mostrar un mensaje de "la página no ha sido encontrada".
- Sección oficial de interrupciones de servicio de EPM: https://www.epm.com.co/clientesyusuarios/interrupciones-del-servicio/energia/
- Plataforma de consulta de interrupciones EPM: https://aplicaciones.epm.com.co/interrupcionesenergia/
- Consejo para la obtención de la muestra:
  - Si por restricciones del portal corporativo de EPM no se encuentra una descarga histórica en bloque CSV, se puede descargar o copiar el boletín en formato de tabla de interrupciones programadas del mes actual.
  - También es posible buscar datasets de energía de EPM directamente en datos.gov.co con términos como "Interrupciones EPM" o "Tarifas EPM".
  - Esta opción es suficiente para completar la bitácora de muestra.

## 4. SUI (Sistema Único de Información - Superservicios)

- Portal de consultas y reportes: https://www.sui.gov.co/
- Ruta sugerida:
  - Ir a Reportes y Consultas Públicas
  - Energía Eléctrica
  - Informes Comerciales / Consumo por Municipio

## 5. OpenStreetMap (Límites municipales / GeoJSON)

- Para OpenStreetMap, la forma más directa de descargar el archivo GeoJSON sin lidiar con consultas avanzadas o errores de timeout es usar la herramienta Overpass Turbo o la API de boundaries.maplogs.
- Opción 1: Overpass Turbo (recomendado)
  - Enlace: https://overpass-turbo.eu/
  - Pasos:
    1. Abrir el enlace.
    2. Borrar el código del panel izquierdo y pegar este script para buscar los municipios de Antioquia:

      ```text
      [out:json][timeout:60];
      area["ref"="05"]["boundary"="administrative"]->.searchArea;
      (
        relation["boundary"="administrative"]["admin_level"="6"](area.searchArea);
      );
      out body;
      >;
      out skel qt;
      ```

    3. Hacer clic en el botón Ejecutar (Run) en la parte superior izquierda.
    4. Cuando se dibujen los elementos en el mapa, hacer clic en Exportar -> GeoJSON o descargar directamente los datos.

- Opción 2: Descarga rápida desde OSM Boundaries (descarga directa por municipio)
  - Enlace: https://wambachers-osm.website/boundaries/
  - Navegar: Colombia -> Antioquia -> Medellín
  - Seleccionar la opción de exportar como GeoJSON.
  - Guardar este archivo en la carpeta de muestras con el nombre: `osm_poligonos_antioquia_20261003.geojson`

## Resumen

Las fuentes documentadas abarcan:
- información geográfica y catastral de municipios,
- clima horario para Medellín,
- interrupciones y tarifas de servicio de EPM,
- reportes del Sistema Único de Información de Superservicios,
- y límites municipales de OpenStreetMap en formato GeoJSON.
